# World

Datasets that cover all countries, such as country codes, currencies, languages,
time zones, units of measure and per-country format rules (IBAN structure, tax
ID formats, postal code patterns).

Path pattern: `data/world/<dataset>/`

| Dataset | Contents |
| --- | --- |
| [`currencies`](currencies/) | ISO 4217 currency codes, the entities using them, historic codes |
| [`units-of-measure`](units-of-measure/) | UN/ECE Recommendation 20 unit codes, conversion factors and unit sets |

See the [roadmap](../../docs/roadmap.md#world) for what is planned.
