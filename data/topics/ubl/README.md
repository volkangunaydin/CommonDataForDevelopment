# UBL

Reference data for [OASIS Universal Business Language (UBL)](https://www.oasis-open.org/committees/ubl/),
the XML document standard behind many national e-invoicing systems.

Path pattern: `data/topics/ubl/<dataset>/`

## Scope

- Document types defined by UBL (Invoice, CreditNote, DespatchAdvice, Order, …)
- Code lists referenced by UBL documents (document type codes, tax category
  codes, payment means codes, unit codes)

Data specific to a national or regional UBL customisation (UBL-TR, Peppol BIS)
belongs under [`e-invoicing`](../e-invoicing/).

The UBL schemas themselves (XSD files) are published by OASIS and are not copied
here; datasets link to the official distribution.
