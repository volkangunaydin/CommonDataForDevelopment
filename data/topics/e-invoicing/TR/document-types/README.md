
# Electronic document types of Türkiye (e-Belge overview)

Short catalogue of the electronic documents and related applications used in
Türkiye's e-Belge system. Definitions follow Vergi Usul Kanunu General
Communique No. 509; e-Defter is listed as a related ledger application from
GİB's technology overview.

| File | Rows | Description |
| --- | --- | --- |
| [`document-types.csv`](document-types.csv) | 14 | Document / application overview |
| [`datapackage.json`](datapackage.json) | – | Metadata and field schema |

## Notes

- This is an **overview**, not the UBL-TR code lists (those live in sibling
  folders under `e-invoicing/TR/`).
- `is_e_belge=false` only for `e-defter` (electronic ledgers).
- Mandate thresholds and transition dates change by Communique amendment; they
  are not duplicated here—see the current VUK 509 text.
